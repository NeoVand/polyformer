## 1a. Newton on enwik8

**Claim:** softmax + Newton gives 1.657 bits per character versus softmax 1.651; Newton alone gives 2.497.
**Evidence:** `190f5479` (19 Oct 13:12 CDT), `research/lm.py::{init,newton_attention,forward,main}`, `research/modal_run.py::lm_a`, `research/results/lm_a.jsonl`. Bits per character are average negative log probability in base two; lower is better.
Recomputed means: GPT **1.6504667**, hybrid **1.6570667**, Newton-only **2.4965667**. Hybrid-minus-GPT by seed: **+0.0121, +0.0138, −0.0061**. The quoted 1.651 baseline is an imprecise rounding, not the underlying mean.
**Precision suspicion:** the first run predates `ace2673a` (19 Oct 15:39), which introduces `Precision.HIGHEST` for weighted subset products. But old Newton computes `cumsum(phi**j) - phi**j`: these are float32/complex64 sums and elementwise products, **not matrix products susceptible to TF32 in the power-sum accumulation**. Its projections/readout use default matmul precision. TF32 is reduced-precision GPU matrix arithmetic; the later fix protects a different computation. There is no code evidence that this fix rescues `lm_a`.
**Inputs and masks:** Newton has learned phase and gate projections of every input token, then a learned output projection. It has no separate key/value path or query-dependent selection of past tokens by design; it is not accidentally disconnected. Hybrid runs softmax first, then Newton on that updated state. Gradients to phase/gate/readout and past inputs were nonzero; future-input gradient was zero. Historical GPT/hybrid/Newton forward tests changing every future token gave exactly zero change to earlier outputs.
**Algebra:** `e_0=1`, `m e_m=Σ_{j=1}^m (−1)^(j−1)e_{m−j}P_j`; exclusive prefixes and division by `C(t,m)` are correct. Impossible arities at early positions are zeroed; the current token supplies the root factor, appropriate when predicting the next byte. Against a float64 product-coefficient reference, float32 normalized coefficient errors were below **6.6e−8** for orders through four at lengths 8, 256 and 512 on random bounded phases. This is a stress sample, not a bound for trained activations.
**Found — medium, plausible false negative:** dividing by `C(t,m)` *before* `f/sqrt(mean(f²)+1e−6)` makes the purported unit-size normalization fail when the feature is small. With independent magnitude-0.5 phases at length 256, arity-four RMS was **2.21e−5**, leaving approximately **0.022** RMS after normalization. In a historical width-256/rank-64 initialization on random byte IDs it was **0.266–0.292**, versus ~1 for arities one/two. The floor suppresses long-prefix higher-order features; cancellation error was much smaller in these tests. How much this happened during training is **unverified**.
**Fairness:** all arms use batch 64, context 256, 8,000 steps, learning rate 0.001, 400 warm-up steps, the same decay and seeded data order. Parameter counts are 3,290,624 / 3,297,792 / 3,295,744; MLP widths 1024 / 768 / 1024. The same rate is not independently tuned for each arm. This is parameter matching, not compute matching. Validation is 512 fixed random windows from the 5M-byte validation split, not the final 5M-byte test split.
**Verdict: HOLDS as a small-scale recorded null; DOUBTFUL as evidence that Newton cannot help language.** The TF32 explanation is unsupported; the normalization issue and missing per-arm rate tuning are concrete reasons for a limited retest.
**Cheapest settling rerun:** first log per-arity feature/gradient sizes on historical settings; then GPT, original hybrid, and hybrid with a scale-aware normalization floor, three paired seeds and unchanged schedule, followed by a small rate sweep only if the correction matters. About **$2–4** at archived 58–109 s/run plus startup. A positive result must survive fresh validation and compute matching.

## 2. Newton on SET/Match-k, and the characters law

**Claim:** shared, normalized Newton at rank 256 solves SET/Match-3/Match-4 and reaches 84.8% on Match-5; exactness requires all 40 character pairs, with accuracy ~1/2 + F/80.
**Evidence:** `research/polybench.py::{task_set,task_set4,task_matchk,_zero_sum_members,attention,newton_diagnostics}`, `research/summarize.py`, `results/newton_{a,b,c,d,e,f,fig}.jsonl`; initial Newton `aaaed5ee`, probes `f3aaee46`, normalization/result bundle `190f5479`. Oracle `research/charlaw.py` and discussion `FORMALISM.md` enter `ace2673a`.
A character is a complex phase assigned to a group element so that multiplying phases corresponds to adding elements. It matters because the zero-sum test becomes an exact sum of products. Here there are 81 characters: the constant plus **40 conjugate pairs**, not 40 individual complex characters.
**Recomputed:** `newton_e`, shared+normalized, rank 256: SET/Match-3/Match-4/arity all 1.0000 on three seeds; four-card SET **1.0000/1.0000/0.9960**; Match-5 **0.8605/0.7804/0.9017**, mean **0.8475333**. Rank 256 is **per head**, four heads, hence 1,024 complex channels and about 300k parameters. Rank-512 Match-5 mean is 0.9748667.
**Generators/scoring checked:** cards sampled without replacement, labels depend only on explicit distinct-index subsets, BOS masked from the loss, training RNG separate from evaluation seed `10000+seed`, final rather than best checkpoint reported. Independent subset enumeration matched all labels on 60 tables each of SET, four-card SET and Match-3/4/5. Balanced accuracy is the mean recall over present classes, correctly masked; `summarize.py` averages these records correctly. No label or evaluation leakage found in the training path. Stored rounded scores cannot certify literally zero mistakes.
**Exact identity:** character orthogonality gives the witness count `N_q,k=[C(n−1,k−1)+2 Σ_a Re(chi_a(x_q)e_{k−1}(chi_a(x_others)))]/81`. Independent checks matched every label on 60 tables per Match-3/4/5, integer-count errors <4.3e−15. This proves sufficiency of the exact full basis plus the right readout, not necessity for arbitrary classifiers.
**Found — medium, implementation/theory mismatch:** Newton's leave-one-out sums include the learned BOS token, but divide by `C(T−2,m)`, appropriate only after removing BOS as well as the query. Thus `e_m(real+BOS)=e_m(real)+phi_BOS e_{m−1}(real)`: lower arities contaminate the claimed pure feature unless its gate vanishes. This is not a label leak. It can weaken arity attribution or learning; whether trained BOS gates effectively remove it is **unverified**. The fixed RMS floor also prevents exact cancellation of an arbitrary normalization constant.
**Probe checked:** `newton_diagnostics` fits characters to 512 evaluation tables, uses gate-weighted phase alignment >0.9 and merges conjugates. It never reads target labels to count characters. Correlation on the 74 single-arity Match runs is **0.997123**; maximum deviation from 1/2+F/80 is **5.10 percentage points**, not strictly ≤5. Across all 132 stored Newton character probes, “F=40 iff accuracy≥0.9999” holds, but “iff accuracy=1” has two counterexamples at 0.9999. At threshold 0.999, one four-card SET run has F=39 and 0.9998. The exactness threshold matters.
**Found — high, inferential overclaim:** a >0.9 phase probe is neither an exact algebraic certificate nor an exhaustive representation test. Gate amplitudes, residual input, MLP and other channels remain. Correlation plus a finite MLP experiment cannot establish “every readout needs all 40” or a necessary/sufficient training law. The observed association is real; the universal theorem is unsupported.
**Found — medium, oracle test leakage:** `charlaw.main` calls `threshold_ba(Xte.sum(...),yte)`, choosing the sum threshold on the test labels. Logistic/MLP training uses separate tables and is not affected. In a fresh 1,000/1,000-table check with 20 characters, train-selected threshold gave **0.77397**, test-selected **0.77824**. This is an optimistic oracle comparator, not a clean held-out result; the published oracle table also misses the linear law by up to 5.9 points. Its Gaussian explanation assumes independent subset sums even though subsets overlap; its fitted constant is not a theorem.
**Verdict: HOLDS for the synthetic scores and exact counting construction; DOUBTFUL for the universal characters law.** Literal “all rank-256 tasks exact” is BROKEN by four-card SET and Match-5; the original detailed table is more careful.
**Cheapest settling rerun:** freeze thresholds on training data; enumerate all 81 cards at every position for the phase probe; sweep the probe cutoff; repeat shared rank-256 Match-4/5 with/without BOS and the scale-aware floor, three seeds, fresh tables. **$3–6** at archived 52–53 s/run plus diagnostics/startup. The oracle/probe-statistics correction itself costs **$0 locally**. Necessity needs a proof or explicit feature-collision construction, not another small MLP.

## 3. Free-field generating function

**Claim:** `exp(mu z) prod_t(1+z p_qt phi_t)` unifies subset coefficients, a softmax special case, empty slots and a separate walk sector; generic trilinear cubic scores are not included.
**Evidence:** `ace2673a` `research/FORMALISM.md` §§2–3, `polybench.py::subset_moments`, `lm.py::{subset_moments,walk_sector}`; causal walks/look-back and expanded tests in `3ea0a5e7`. Results `sfa_{a,b}.jsonl` and `lm_sfa{,_b}.jsonl` support prototypes, not a physical field theory.
**Re-derived:** expanding the product gives `E_m=Σ_{i=0}^m e_i(p phi) mu^(m−i)/(m−i)!`. Taking a logarithmic derivative gives `mE_m=Σ_{j=1}^m(−1)^(j−1)E_{m−j}(P_j+mu*1[j=1])`. At mu=0, dividing by `e_m(p)` is the expectation of the channel product under distinct m-subsets weighted by `prod p_t`. The exponential adds a factorial-weighted number of empty slots; its missing Poisson normalizer cancels in the ratio. These identities hold exactly where the denominator is nonzero.
**Softmax qualification:** `A_1=Σp_t phi_t` only at mu=0 and normalized weights. At mu>0 it is `(Σp_t phi_t+mu)/(1+mu)`; multiplying by the root `phi_q` further gates the output. The actual model contains ordinary softmax through its separate linear-value path. Thus “m=1 is softmax” is true with stated qualifications, false for the whole rooted/vacuum branch without them.
**Trilinear qualification:** additive pair logits `s_qj+s_qk` have zero rectangular mixed difference; a trilinear logit has `Σ_a q_a(k_ja−k_j'a)(k_ka−k_k'a)`, generically nonzero. This proves non-inclusion of generic cubic *routing*, not a limit on all outputs obtainable with arbitrarily wide value features or depth.
**Found — medium, wrong supporting diagnostic:** the note's “additive pair-weight matrix has rank one” ignores excluded repeated indices. With positive weights the allowed pair matrix is `diag(p)(11ᵀ−I)diag(p)`, full rank for n>1. The mixed-difference proof survives on allowed rectangles; the claimed masked-matrix rank test does not.
**Walk identity:** for `M=I−uA`, the determinant lemma gives `∂_eta log det(M+eta v a_qᵀ)|0=a_qᵀM^−1v`; expanding the inverse enumerates walks for |u|<1 when A is stochastic, or formally as a series. Principal-minor expansion gives the mixed subset/walk terms. An independent 5×5 numerical check matched the determinant expansion within **4.5e−16**.
**Found — low, indexing typo:** if `a_qᵀ` is row q of A, `a_qᵀ A^ell V` is `(A^(ell+1)V)_q`, not the preceding definition `(A^ell V)_q`. Use `e_qᵀA^ell` or shift the index. The implemented walk recurrence and explicit-path tests are correct.
**Verification:** `nice -n 19 .../python research/test_sfa.py` passed all 20 checks, including float64 subset/bosonic enumeration, strict-past masks, empty first position, explicit walks and no future leak. Vacuum stability is a measured approximation, not exact arithmetic; high arity/small mu can still be ill-conditioned. No trained-activation bound was verified.
**Verdict: HOLDS for the coefficient identities, qualified softmax case and generic cubic non-inclusion; BROKEN for the masked rank-one diagnostic and walk indexing sentence.** Neither error invalidates the prototype results. The physical terminology and claim that the interacting sector “can represent everything” remain unverified interpretive claims.
**Cheapest settling rerun:** correct the two statements and add allowed-rectangle/one-hop indexing tests, **$0 local / no Modal needed**. No training rerun can settle an algebraic universality claim.

## 5. Coupling barrier and order-k blindness

**Claim:** degree-two three-role logits have query-independent double-centered coupling; scores using fewer than k roles have equal class means on uniform zero-sum k-tuples.
**Evidence:** `research/PLAN.md` T1/T2, `FORMALISM.md` §§1–2; `src/lib/model/{reference.ts,operators/strassen.ts,operators.spec.ts}`, `src/lib/learn/figures.ts`; these constructions/tests are present at `37bd5ae5`. There is no separate empirical result required for the theorem; the numerical demonstration is in `operators.spec.ts`.
**Proof, coupling:** a total-degree≤2 polynomial in separately supplied q,u_j,v_k decomposes as `L_q(j,k)=c(q)+a_q(j)+b_q(k)+u_jᵀCv_k`, including pure-key quadratics in a/b. With fixed row/column sets, `H_n=I−11ᵀ/n` annihilates the first three terms, so `H_n L_q H_m=H_n U C Vᵀ H_m`, independent of q. Independent random numerical check: discrepancy **3.6e−15**.
**Scope:** this is raw finite logits with fixed role features. Query-dependent masks, nonlinear processing of logits, exponentiation, or previous-layer context-dependent keys need separate analysis. The double-centered *probability* matrix generally depends on q; the theorem does not say otherwise. Masked −infinity entries cannot simply be centered. On common allowed rectangles the mixed-difference argument remains valid.
**Proof, blindness:** let independent uniform `X_1,...,X_k` lie in finite group G and `Y=1[ΣX_i=0]`. After fixing any proper subset of coordinates, a remaining uniform coordinate makes `P(Y=1 | subset)=1/|G|`. Thus every integrable function of those coordinates, and any sum of such functions, has equal class means. This is an expectation statement, not equality of whole-score distributions or impossibility for nonlinear classifiers.
**Found — high, extrapolation error:** the theorem's with-replacement tuple law is not the entire distinct-card/existential table benchmark. Explicit enumeration in `Z_3^4` gives **39** completing unordered pairs for 120 fixed distinct pairs, versus **38** for the other 3,120 in Match-4. Thus even pair marginals of distinct zero-sum quadruples are not exactly uniform. Theorem T1 explicitly states replacement correctly; the broader prose saying all table labels are invisible, or using T1 to prove deep softmax cannot learn, goes beyond it.
Equal means alone do not forbid a threshold classifier: for two independent ±1 bits, the classes “equal” and “different” have equal mean of `x_1+x_2`, yet thresholding at 1 gives balanced accuracy 0.75. A nonlinear readout of both bits solves the relation exactly. This is a counterexample to the inference, not to T1.
**Verdict: HOLDS for both precisely scoped theorems; BROKEN for unrestricted classifier/depth impossibility or unqualified transfer to distinct-card table labels.** The coupling barrier remains a useful local statement, not a language-model lower bound.
**Cheapest settling rerun:** exact small-group enumeration and an explicit probability-vs-logit centering test, **$0 local / no Modal needed**. A broader lower bound requires new assumptions and proof, not training evidence.

## 6. Nerode metric loss under dilution

**Claim:** the metric objective averages sampled futures, fails ownership tracking under dilution, and the corrected run's gain is mainly the first-owner shortcut; under-training might explain the negative result.
**Evidence:** branch `claude/metric-0160e1` at **`ed271371`**; registration `d6e3ec18`, corrected pairs `628f9bfc`, corrected results `a015309a`; `research/{METRIC.md,para_run.py,dilution.py,lean_run.py,test_metric.py,metric_jobs.py}`, `results/metric/{dil_*.json,verdicts.json,tier2_diag.json}`. Read directly with `git show`, without switching branches.
Nerode equivalence means two histories give the same answer for **every** legal future. A sampled metric is a distance learned from some shared continuations; it can overlook distinctions that are rare or absent in those continuations.
**Exact sampling, original T8.3:** each pair draws r uniformly from 0…4, one shared suffix of r operations, and independent prefixes. Each member's total operation count is uniform 8…20; its first owner is uniform over A/B/C/D. Subsequent operations are 65% transfers/swaps (each endpoint an alias with probability 0.30), 25% alias assignments (target person with probability 0.75), 10% revocations. The suffix and question have identical rendered tokens across the pair. Question wording is drawn uniformly from `PARA_QUESTIONS`; **all versions ask the same final-owner question**, not a sampled semantic query about any state variable. Targets come from `execute`, not the model.
The sampled loss compares states at the prefix junction, each shared operation boundary and '?'; it targets gamma times the stopped next distance, then answer inequality at '?'. Sampled narratives receive no language loss. The separate equivalent-pair term compares training narratives with paraphrases at every boundary and decision. Gamma was selected as 0.5 from pilots {0.5,0.9}.
**Exact sampling, corrected T8.3′:** pairs are the ordinary training interventions: two *different initial owners*, identical random tail and rendering. Paraphrases, if enabled, preserve the whole semantic operation sequence. Unrelated pairs are batch row i versus i+2 and enter only at the final answer. No random suffix loss is used here. Distance is half the centered cosine distance, terminal target `(1−gamma)1[answers differ]`, gamma=0.9, loss multiplied by `1/(1−gamma)^2=100`. Every arm trains 1,500 steps, batch 64, lr 0.002, 100 warm-up; two layers, width 64, MLP 128.
**Checked code/data:** shifted packing excludes the answer from inputs and marks '?' correctly; shared-future boundaries and stopped gradients pass the historical tests. Independent parsing/execution of 1,000 intervention pairs found no semantic label errors; their owners differ at **every boundary**, not only at the answer. In 1,000 original sampled pairs, every answer matched the interpreter. Probe fitting splits by pair: first 128 pairs train, next 128 test, avoiding paired-member leakage.
**Math qualification:** for a finite complete deterministic machine, gamma>0 and full support on every symbol, `d=c Σ_t gamma^t E[output disagreement after t shared symbols]` is zero iff all finite continuations agree. Averaging does **not by itself destroy the exact zero-set theorem**. Finite sampling, a maximum four-operation suffix, discounting and restricted questions give no such guarantee here. Rare decisive futures are a plausible limitation, not a demonstrated cause of these runs. On rewrite trees, only shared applicable rewrites are sampled, with no-common-rewrite pairs masked; that is also a restricted domain.
**Found — high, objective cannot identify the desired computation from intervention pairs alone:** with shared aliases, every transfer permutes owner identities; initially different owners therefore stay different. Their inequality target is always one regardless of how ownership changes. An equal-distance code for the **initial** owner has the same distinction signal as a code for the current owner. Paraphrase invariance does not fix this. Unrelated final-answer comparisons and language loss can break the ambiguity, but the intervention part supplies no supervision selecting the actual permutation. This is a stronger concrete explanation than simply “random futures are too dilute”; it does not prove the full loss has a shortcut global optimum.
