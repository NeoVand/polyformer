# R7 · Talent identification (picking children who will be elite adults)

## 1. Objects and techniques
Objects: the **relative age effect** (academies over-select children born just after the cut-off: older, not better); the **test battery** (NFL Combine: fixed, electronically timed drills); **maturity offset** (years from the growth spurt, from body measurements).
Techniques: **bio-banding** (compare within bands of biological maturity, not birth year); **representative design** (Brunswik: a test predicts only if it samples competition's cues); Poulton's **closed** (self-paced: a free throw) vs **open** (reactive) skills; **ISAK accreditation** (a measurer passes reference subjects within a stated **technical error of measurement**, then goes unchecked).

## 2. Map to the problem
- **P1**: selectors commit before the outcome exists. Ours: whoever acts on outputs uncheckable in time.
- **P2**: a child is never that size again. Cheap checkers need the input; if it is not kept (streamed, deleted for privacy), only the instrument's certificate remains.
- **P3**: sport bans the tool by definition (a car beats a sprinter); ours: no-tool measurement of the model itself.
- **P4**: closed skills are bounded-view; gymnastics difficulty scoring is a finite element catalogue plus bonuses read from adjacent elements.
- **P5**: gymnastics splits a countable difficulty score from a judged execution score; only the countable one can be appealed. A certified part confines disputes to recognition.
- **P6**: our GSM8K loss is a relative-age effect (small numbers favour the head); bio-band by predicted head failure.
- **P7**: accreditation = level + tolerance + renewal when the instrument changes; ours: weights, view set, GPU, float-error bound.

## 3. Map from the problem
Our theorem (steps reading earlier steps admit no finite certificate) explains why drill batteries predict team-sport careers weakly: play reads unbounded history. Conjecture (literature unchecked): batteries predict best in closed-skill sports.

## 4. Ideas
**I1. Defer by Chow's rule, report by band.** Chow's rule (1970): answer only when your expected error is below the cost of handing off. The certificate fixes the sheet's execution error at zero, so the router needs only head error per item (fitted on held-out items from digit counts and carries, like a maturity offset) and translation error; route when the first is larger; report per pre-registered band. *Who*: us; any certified/uncertified mix. *Breaks*: nothing. *Kill*: on fresh GSM8K at 4B, routed accuracy below head-only + 1 point, or under 5% of items in the routing band.

**I2. Accredited instrument for unkept inputs.** Certify once; attach the attestation (weights, view set, GPU, tolerance) to each output, delete the input; receivers trust numbers from data they never saw. *Who*: on-device health or finance apps under data-minimisation law. *Breaks*: the product is the certificate. *Kill*: a signed conventional program in a trusted execution environment (hardware attesting which code ran) matches it on the same inputs; I expect so.
